# Настройка VK бота на PHP (Callback API)

Бот работает через **Callback API**. Это требует, чтобы ваш сервер (хостинг) был доступен из интернета по публичному адресу.

## 1. Подготовка в VK

1. Зайдите в **Управление** -> **Работа с API** -> **Callback API**.
2. Вкладка **Настройки сервера**:
   - Найдите строку, которую должен вернуть сервер (например: `Строка: 1a2b3c4d`).
   - Скопируйте её.
3. Вкладка **Типы событий**:
   - Включите **Входящие сообщения**.

## 2. Установка на хостинг

1. Загрузите файлы `index.php`, `data.php` и `.env` в корневую папку вашего сайта (обычно `public_html` или `www`).
2. Отредактируйте файл `.env` на сервере:
   ```env
   VK_TOKEN=ваш_токен_сообщества
   VK_GROUP_ID=ваш_id_группы
   CONFIRMATION_TOKEN=строка_из_настроек_vk
   SECRET_KEY=любой_пароль_на_ваш_выбор (опционально)
   ```
3. Убедитесь, что у скрипта есть права на запись в текущую папку (нужно для создания папки `sessions/`).

## 3. Привязка к VK

1. В настройках Callback API в VK укажите **Адрес**: `https://ваш-сайт.ru/index.php`.
2. Если вы указали `SECRET_KEY` в `.env`, введите его в поле **Секретный ключ** в VK.
3. Нажмите **Подтвердить**. Если всё верно, статус сменится на "Адрес подтвержден".

## Структура файлов
- `index.php` — основной обработчик запросов от ВК.
- `data.php` — вопросы и логика тестов.
- `.env` — файл с настройками и ключами.
- `sessions/` — папка для хранения прогресса пользователей (создается автоматически).
